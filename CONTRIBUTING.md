# Contributing to Awesome Agent Skills

Thanks for considering a contribution. This list is **opinionated** by design — that's what makes it useful — so the bar for new entries is high.

## Quality bar

Your PR will be merged if **all** of the following are true:

1. **You've used the skill in a real project**, not just read its README. We can usually tell from the way you describe it.
2. **You can describe `When not to use it`.** Every skill has a downside. If you can't articulate one, you don't know it well enough yet.
3. **The linked repo is open-source** with a permissive license (MIT, Apache-2.0, BSD, CC0, public domain). GPL/AGPL skills are linkable but flagged.
4. **No duplicates.** Search the existing list first.
5. **The skill solves a real, named problem.** Not "general improvements."

## Submission template

Use this exact format (and keep it tight):

```markdown
### [skill-name](https://github.com/owner/repo)

- **What it is:** _one sentence — be specific about what behavior changes_
- **When to use:** _real use case from your experience_
- **When not:** _honest downside — every skill has one_
- **Why it works:** _1-2 sentences on the mechanism_
```

Add a 🌟 emoji **only** if the skill is exceptional and you're confident reviewers will agree. Reserved for the top 5-10% of entries.

## Empty categories

The README marks several categories as "Underserved" or "Empty":

- Rust skills
- Go skills
- Frontend / UI skills
- Backend / API skills
- Game development skills
- Security-focused skills
- Test-driven skills

If you fill one of these gaps with a quality entry, your PR will be merged quickly. You'll also be credited in the README.

## What we will NOT accept

- **Self-promotion of low-quality skills.** "I wrote this last weekend" is not enough; production-tested only.
- **Auto-generated lists** that include every skills-tagged repo. The whole point of this list is curation, not coverage.
- **Skills with disabled safety behaviors** (jailbreaks, "ignore previous instructions"). Hard pass.
- **Affiliate links or sponsored entries.**
- **Skills that are 90% flattery prompts.** ("You are an expert god-tier engineer.") We're a list of useful skills, not roleplay templates.
- **Skills locked to a specific paid tool** unless that tool is dominant (Claude Code, Cursor, Codex, etc.). Self-hosted / open-source clients first.

## Reporting a low-quality entry

If a listed skill no longer holds up — outdated, broken, abandoned by maintainer, or just not as good as we said — open an issue with:

1. The exact entry name
2. What you observed when you tried it
3. Whether you'd suggest removing or moving it to a less prominent category

We will check, and if you're right, the entry will be removed or downgraded.
